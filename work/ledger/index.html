Open the live demo →

Overview

A dashboard concept for the owner of a Telegram shop bot, designed in the spirit of tools like Linear and Stripe: an 8-pixel grid, Inter at 13px with tabular numbers, hairline borders and a single accent colour.

How it works

KPIs with sparklines, a revenue chart with axes, crosshair and 7/14/30-day ranges, a sortable table with bulk actions and a drag-and-drop board. A ⌘K command menu, keyboard navigation (j/k, x, 1/2, /) and an order panel with an activity log. All data is simulated in the browser; nothing is sent.

This is a personal concept: the brand, data and people in it are fictional.
