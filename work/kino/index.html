Open the live demo →

Overview

A cinema booking flow for a fictional cinema. Posters are generated in SVG, sessions change the hall occupancy, and the seat map is drawn as a curved hall with a centre aisle and recliner rows priced separately.

How it works

Seats can be chosen by tap or with arrow keys and Space; the summary updates with a line per seat type. Booking produces a ticket card with a demo code pattern — clearly marked as not valid for entry. Films, prices and the cinema are fictional.

This is a personal concept: the brand, data and people in it are fictional.
